DOS攻击之Fork bomb Fork bomb是一种恶意程序，它通过递归调用自身来创建大量的进程(进程递归式派生)，从而耗尽系统资源，导致系统无法正常运行甚至崩溃。这种攻击通常被称为拒绝服务攻击（DOS攻击），因为它会使系统拒绝为其他用户或服务提供服务。 原理与影响 Fork bomb的工作原理是利用系统调用fork（或其他等效的方式）来创建新的进程。在类UNIX系统中，fork函数用于创建当前进程的一个副本。Fork bomb通过递归调用自身，创建大量的进程，这些进程会迅速消耗系统分配给进程的可用空间，使进程表饱和。一旦进程表饱和，系统就无法再运行新的程序，除非有进程终止。由于Fork bomb创建的进程会不断尝试创建新的进程，即使有进程终止，系统也很难有机会运行新程序。 此外，Fork bomb生成的子进程会占用CPU和内存资源，导致系统与现有进程运行速度放缓，响应时间增加，最终可能导致系统无法正常完成任务，严重影响系统的正常运作。 示例 以下是一个简单的shell脚本示例，它在类UNIX系统中触发Fork bomb： 1:() { :|:& } ...
